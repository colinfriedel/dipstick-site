# dipstick.colinfriedel.com

The Dipstick website: a home page and the privacy policy (`/privacy/`).
Plain HTML and CSS, no build step. Deployed on Vercel.

The privacy policy's source text is also in the app repo at
`Dipstick/docs/privacy-policy.md`; keep them in sync.
